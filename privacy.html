Privacy Policy

Wadona Studio Threads Tool ・ Operated by 株式会社ワドナスタジオ (Wadona Studio) ・ Effective date: October 16, 2026

This policy explains how the Wadona Studio Threads Tool (the "App") collects, uses, stores and deletes data obtained through the Threads API provided by Meta Platforms, Inc. The App is an internal tool. It is used only by Wadona Studio to manage and plan content for its own Threads account, @ichi_ai_lab. It is not offered to the public.

1. Data we access

Data about our own account

  • Our own profile information, posts, replies and insights (views, likes, replies, reposts, quotes, shares, follower count), accessed with our own authorization.

Public data about other Threads users

  • Keyword search (threads_keyword_search): public posts that match keywords related to our niche — post text, username of the author, date, media type and link.
  • Profile discovery (threads_profile_discovery): for a small number of public accounts that we choose, the username, display name, biography, follower count, and the public totals for the last 7 days (views, likes, replies, reposts, quotes).

We do not access private accounts, direct messages, email addresses, phone numbers, location data or any other non-public information. We do not use the App to collect data about people under 18 on purpose.

2. How we use the data

  • To understand which topics and post structures are useful to people in our niche, so we can write our own original posts.
  • To choose a few reference accounts of a similar size and study how they organize their profiles and posts.
  • To measure the performance of our own posts and improve them.

The App is read-only toward other users. It never posts, likes, follows, replies to, mentions or sends messages to other users. We do not copy other people's posts.

3. What we do not do

  • We do not sell, rent, license or trade any data.
  • We do not share data with third parties, data brokers or advertising networks.
  • We do not use the data for advertising targeting, profiling of individuals, surveillance, or eligibility decisions (such as employment, credit, housing or insurance).
  • We do not publish other users' data.
  • We do not combine the data with data from other sources to identify individuals.

4. Storage, security and retention

  • Data is stored only on a computer managed by Wadona Studio. It is not uploaded to any cloud server or shared database.
  • Access tokens are stored in a local configuration file that only the operator can read. They are never shared.
  • Public data about other users is deleted within 30 days after it is collected. Aggregated notes that do not identify any user (for example, "posts with a question in the first line got more replies") may be kept.

5. Your choices and data deletion

If you are a Threads user and want us to delete any data about you, or want to know whether we hold any, please follow the steps on our Data Deletion Instructions page. We will delete the data and confirm within 7 days.

6. Compliance with Meta's terms

We use data from the Threads API only in line with the Meta Platform Terms and Developer Policies. If Meta's terms change, or if our access ends, we will delete the related data.

7. Changes to this policy

If we change this policy, we will update this page and the effective date above.

プライバシーポリシー（日本語）

本ポリシーは、株式会社ワドナスタジオ（以下「当社」）が運営する「Wadona Studio Threads Tool」（以下「本アプリ」）が、Meta Platforms, Inc. の Threads API を通じて取得するデータの扱いを定めるものです。本アプリは当社の Threads アカウント（@ichi_ai_lab）の運用と企画のためだけに使う社内ツールで、一般には提供していません。

1. 取得するデータ

当社アカウント自身のプロフィール・投稿・返信・インサイト。ほかの利用者については、公開されている情報のみ（キーワード検索に該当した公開投稿の本文・投稿者名・日時・リンク、当社が選んだ少数の公開アカウントのプロフィールとフォロワー数・直近7日の公開合計値）。非公開アカウント、DM、メールアドレス、電話番号、位置情報など公開されていない情報は取得しません。

2. 利用目的

当社のジャンルで役立っている話題・投稿の構成を把握して当社オリジナルの投稿を作るため、近い規模の参考アカウントを選ぶため、当社投稿の成果を測って改善するため。本アプリはほかの利用者に対して閲覧のみで、投稿・いいね・フォロー・返信・メンション・DMは一切行いません。他人の投稿を複製しません。

3. 行わないこと

データの販売・貸与・第三者提供、広告ターゲティング、個人のプロファイリングや監視、雇用・与信・住宅・保険などの判断への利用、他人のデータの公開、他の情報源と組み合わせた個人の特定は行いません。

4. 保存・安全管理・保存期間

データは当社が管理するコンピュータにのみ保存し、クラウドや共有データベースには置きません。アクセストークンは運用者だけが読める設定ファイルに保管します。ほかの利用者の公開データは取得から30日以内に削除します（個人を特定しない集計上の気づきは残すことがあります）。

5. 削除の依頼

ご自身に関するデータの削除や保有の有無の確認は、データ削除のご案内の手順でご連絡ください。7日以内に削除し、ご連絡します。
