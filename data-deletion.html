Data Deletion Instructions

Wadona Studio Threads Tool ・ Operated by 株式会社ワドナスタジオ (Wadona Studio) ・ Last updated: October 16, 2026

The Wadona Studio Threads Tool is an internal tool used only by Wadona Studio. It stores data only on a computer managed by Wadona Studio, and it automatically deletes public data about other users within 30 days. You can also ask us to delete your data at any time.

How to request deletion

  1. Send an email to edit@wadona.com with the subject "Data deletion request".
  2. Include your Threads username (for example, @yourname).
  3. We will delete all data related to your username, including posts and profile numbers collected through the Threads API.
  4. We will reply within 7 days to confirm that the deletion is complete.

We will not ask you for a password or any other personal information.

If you authorized this app

Only Wadona Studio's own account authorizes this app. If you have authorized it and want to remove it, open Threads, go to Settings → Account → Website permissions, and remove the app. All data related to your authorization will then be deleted within 7 days.

データ削除のご案内（日本語）

本アプリは株式会社ワドナスタジオだけが使う社内ツールです。データは当社が管理するコンピュータにのみ保存し、ほかの利用者の公開データは取得から30日以内に自動で削除します。いつでも削除をご依頼いただけます。

削除の依頼方法

  1. edit@wadona.com に、件名「Data deletion request（データ削除の依頼）」でメールしてください。
  2. 本文に Threads のユーザー名（例: @yourname）をお書きください。
  3. Threads API で取得した、そのユーザー名に関するデータ（投稿・プロフィールの数値）をすべて削除します。
  4. 7日以内に削除完了をメールでご連絡します。

パスワードなどの個人情報をお尋ねすることはありません。

本アプリを許可された方へ

Threads の「設定 → アカウント → ウェブサイトのアクセス許可」から本アプリを削除してください。許可に関するデータは7日以内に削除します。
